# 课表、日程与校园地图（2026-10-19）

对齐清单第 3–5 项。结论分两类：**已验证** = 纯逻辑/界面，测试可复现；**未验证** = 需要一次真实会话或真机目测。

## 1. 多课表

存储布局：

```
timetable.profiles        [{id, name}]
timetable.activeProfile   <id>
timetable.courses.<id>    [course, …]        每张表一个文档
```

- 旧版单表键 `timetable.courses` 在首次读取时迁移成 `default` 表；**先写副本再删旧键**，中途失败不丢数据。
- 名字为空的表就是默认表，界面显示本地化的「我的课表」——不把某一种语言写进用户数据。
- 最后一张表不能删：没有表就没有网格可显示，也没有地方加课。
- `Course` 新增可选 `startTime` / `endTime`（`HH:mm`）。导入的课通常带时间；手工课可填。

## 2. 周视图 / 月视图

- **周**：7 天 × 12 节，块高 = 连上节数，颜色按课程名稳定散列（同一门课永远同色）。
- **月**：固定 42 格（周一开头、6 行），切月不跳高度；圆点 = 当天课程数，方块 = 有日程；
  点某天看当天课程 + 日程。
- 两个视图共用 `coursesOnDate(courses, date, firstWeekStart)`，不会对「这门课这周上不上」给出不同答案。

## 3. 日程重复规则

`RepeatRule { none, daily, weekly, monthly }` + `repeatUntil`（含当天）。

- `AgendaItem.occursOn(date)` 是唯一判定入口，月视图与首页都调它。
- 每月重复按「同一日号」；31 号在小月不出现（不自动挪到月末——挪动会改变用户意图）。
- 完成状态针对这一条任务，不生成下一次。

## 4. 上课提醒（边界写清楚）

- 首页「下一节课」卡：按课程自己的 `startTime` 找最近一节**还没结束**的课；
  进行中显示「正在进行」，≤60 分钟显示分钟数，≤15 分钟标红并在应用打开时提示一次。
- **只有应用在前台才提醒。** 没有引入 `flutter_local_notifications`（新平台依赖 + Windows 通知落地成本），
  所以关掉应用不会有系统通知——这是有意的边界，不假装有。
- 没有 `startTime` 的课程不参与提醒：**不内置作息时间表**，避免把猜的时间显示给赶课的人。
  手工加课可填「上课时间（如 08:00-09:40）」。

## 5. N2151 课表导入

请求（正方公开约定，**未在本校实况验证**）：

```
POST https://jwgl.whu.edu.cn/kbcx/xskbcx_cxXsKb.html?gnmkdm=N2151&layout=default
Content-Type: application/x-www-form-urlencoded
xnm=<学年>  xqm=<3|12|16>
```

响应 `{kbList: [...]}`，行字段 `kcmc / xqj / jcs / zcd / xm / cdmc / qsjsj / jssj`。

解析规则：

- 星期：`1..7` 或 `星期一 / 周一 / 一`；`日 / 天` → 7。
- 节次：`1-2节` / `第3节` → 起始节 + 连上节数；没有数字或结束小于起始 → 跳过该行。
- 周次：`1-16周`、`1-15周(单)`、`1-16周(双)`、`1-8周,10-16周`、`第1-4周`；
  单双周与区间同时出现时先展开再过滤。
- 同一门课、同一时间、同一地点的多段周次（正方常把 1-8 与 9-16 拆成两行）**合并为一条**，周次取并集；
  不合并的话网格会把两块画在同一格上。
- 无法解析的行计数，并在预览里列出原因——不猜。
- 响应按 UTF-8 解码（`http.Response.body` 在没有 charset 时退回 latin1，中文课名会乱码）。
- 覆盖当前课表前弹确认框，框里写明表名与课程数。

**未验证**：真实 `kbList` 字段是否与本约定一致；`xnm` 是 `2026` 还是 `2026-2027`。
拿到一次会话后应把原始响应存到 `%TEMP%`，按真实字段**收紧**别名，不要继续加别名。

## 6. 校园地图

数据：`lib/features/campus_map/campus_data.dart`，332 个设施，抓取于 2026-10-19。

- Overpass 查询（`overpass-api.de` 当时 406/SSL 失败，改用镜像 `overpass.private.coffee`）：
  bbox `30.5290,114.3500,30.5510,114.3770`，取有 `name` 的 `building / amenity / leisure / tourism / shop`。
- 只保留六类：教学、图书馆、餐饮与商店、运动、宿舍、医疗；丢弃银行、彩票、酒店、公交等「其他」。
- 每类内按名字去重；每条保留 `node|way|relation` id 与 OSM 链接。
- 分类优先用 OSM 标签，标签不足时用名字关键词（…食堂 / …教学楼）；位置全部来自 OSM，**没有手工摆点**。
- 投影：等距圆柱 + `cos(纬度)` 修正经度（30.5°N 处一度经度约短 14%），按容器比例居中留边。
- 渲染：`InteractiveViewer` + `CustomPaint`，拖动/缩放；点击 20px 内取最近设施并打开详情。
- 署名：图上常驻 `© OpenStreetMap 贡献者（ODbL）`，点击打开版权页。
- **未做**：瓦片地图（没有 tile provider 协议）、定位（无权限/无 GPS）、主校区以外的数据。
- 第二页保留原 Nominatim 搜索（客户端 1 req/s 限速），用于数据里没有的地点。
